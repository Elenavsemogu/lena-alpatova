# Опросник для Лены Алпатовой

> Цель: понять текущие боли, процессы и желаемый результат, чтобы предложить точное решение (сайт + чат-бот + автоматизация).
> Формат: голосовое / созвон / текстом — как удобнее.

## Блок 1. Про тебя и бизнес (общая картина)

1. **Как ты сейчас в одном предложении описала бы свой бизнес?**
   Что ты делаешь, для кого, и в чём твоя суперсила?

2. **Какие у тебя направления работы сейчас?** (отметь все что есть)
   - [ ] Индивидуальные ПП-рационы (по состоянию здоровья / похудение)
   - [ ] ПП-сладкая выпечка (торты, печенье, десерты)
   - [ ] Преподавание / мастер-классы
   - [ ] Что-то ещё? ___

3. **Какое направление приносит больше всего дохода?**

4. **Какое направление тебе нравится больше всего и хочется развивать?**

5. **Сколько примерно у тебя клиентов в месяц?** (хотя бы порядок: 5-10? 20-30? 50+?)

6. **Какой средний чек?** (за рацион на неделю / за торт / за мастер-класс)

## Блок 2. Текущие процессы (где болит)

7. **Как к тебе сейчас приходят новые клиенты?**
   - [ ] Instagram (DM / комментарии)
   - [ ] Сарафанное радио
   - [ ] Telegram
   - [ ] WhatsApp
   - [ ] Другое: ___

8. **Что происходит когда новый человек тебе пишет? Опиши типичный диалог.**
   (Например: спрашивает что и как → ты выясняешь ограничения → считаешь → отправляешь меню → ...)

9. **Какие вопросы тебе задают чаще всего? Топ-5 повторяющихся вопросов.**
   (Например: «а можно без глютена?», «сколько стоит на неделю?», «а доставка есть?»)

10. **На что у тебя уходит БОЛЬШЕ ВСЕГО времени?** (расставь от 1 — больше всего, до 5 — меньше всего)
    - [ ] Переписка с новыми клиентами (знакомство, выяснение потребностей)
    - [ ] Подсчёт КБЖУ и составление рационов
    - [ ] Организация доставки
    - [ ] Приём оплат и отслеживание кто заплатил
    - [ ] Напоминания клиентам (продление, новый рацион, спецпредложение)
    - [ ] Готовка
    - [ ] Контент для Instagram

11. **Что тебя бесит / утомляет больше всего в рабочих процессах?**
    (Можно просто поныть, это важно)

12. **Были случаи когда ты забывала про клиента / теряла заказ / путала пожелания?**

13. **Где ты сейчас ведёшь записи о клиентах?**
    - [ ] В голове
    - [ ] Блокнот / тетрадка
    - [ ] Заметки в телефоне
    - [ ] Excel / Google Таблица
    - [ ] CRM-система
    - [ ] Нигде, каждый раз заново спрашиваю

    - [ ] Принимать заявки на рационы
    - [ ] Продавать выпечку (торты, десерты)

    (Например: «только натуральные продукты», «без сахара», «готовлю как для своей семьи»)

16. **Какие разделы меню хочешь показать на сайте?**
    (Завтраки / обеды / ужины / перекусы / выпечка / детское / для диабетиков / ...)

17. **Есть фото блюд? Примерно сколько?** (важно для дизайна)

18. **Есть сайты конкурентов или просто сайты которые тебе нравятся визуально?**
