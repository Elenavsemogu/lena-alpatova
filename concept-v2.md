### Общая идея

Сайт = **онлайн-витрина + умная корзина**. Каждая позиция — карточка с фото, составом, ценой, КБЖУ. Клиент собирает корзину, видит полную раскладку по нутриентам и может получить предложение по распределению блюд по приёмам пищи и дням.

Сайт одновременно работает:
- Как **обычный сайт** в браузере (ссылка из Instagram, из поиска)
- Как **Mini App внутри Max** (клиент не выходит из мессенджера)

Клиент указывает свою дневную норму калорий (или выбирает из пресетов), и система предлагает, как распределить выбранные блюда по дням и приёмам пищи:

```
│    Б:28  Ж:22  У:38                             │

│                                                 │
│  [ ← Добавить ещё блюд ]  [ Оформить заказ → ] │
└─────────────────────────────────────────────────┘
```

### Логика планировщика

Алгоритм на JS (работает на клиенте, без сервера):

1. Получает список товаров из корзины с их КБЖУ на порцию
2. Получает целевую калорийность (пресет или ввод)
3. Распределяет блюда по дням так, чтобы:
   - Калорийность каждого дня ≈ целевая (±10%)
   - Более плотные блюда → обед
   - Более лёгкие → завтрак/ужин
   - Сладкое/печенье → перекус
4. Показывает итоговую сводку: средние КБЖУ в день, баланс БЖУ в процентах
5. Если блюд мало на целевое количество дней — подсказка: «Добавьте ещё 2-3 блюда для полноценного рациона на 3 дня»

### Технически

- Чистый **JS на клиенте** — без бэкенда
- КБЖУ хранится в JSON-массиве (каталог товаров)
- Лена обновляет каталог через простую Google Таблицу → скрипт генерирует JSON
- Или мы сделаем простую admin-панель на Google Sheets

## Часть 3. БОТ В MAX

### Почему Max, а не Telegram

Telegram заблокирован в РФ. Max — национальный мессенджер с 2025 года, предустановлен на устройствах. API похож на Telegram Bot API, есть Mini App, JS-библиотека.

### Архитектура

```
Клиент в Max
    │
    ├── Кнопочный бот (сценарии)
    │   ├── Приветствие
    │   ├── Каталог (краткий)
    │   ├── FAQ
    │   ├── Заказ → анкета
    │   └── Связь с Леной
    │
    └── Mini App (сайт внутри Max)
        ├── Полный каталог с карточками
        ├── Умная корзина + планировщик КБЖУ
        └── Форма заказа → уведомление Лене
```
